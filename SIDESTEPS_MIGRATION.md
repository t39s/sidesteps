# sidesteps — техническая миграция (12.11.2026)

## Область и версия

Переименование продукта **Interval Lab → sidesteps** без изменения предметных алгоритмов измерения и без исправления известного дефекта «Начать раньше».

- Исходник: `t39s/dev-sandbox`, коммит `8640c936f3077d521cd34f0d49193d607423159c`, подкаталог `interval-lab-2/`, RC2. Архив исходной сборки проверен по `MANIFEST_SHA256.txt`.
- Тег `interval-lab-2.0.0-rc.2-source` относится к импорту исходной RC2 **до переименования** в локально подготовленную историю нового репозитория. Это **не** тег, созданный в `dev-sandbox`.
- Результат `develop`: кандидат RC2 с обновлёнными брендом, PWA-манифестом, иконкой, именами файлов экспорта и безопасным именованием кэша.
- Новый выпуск RC3 будет выпускаться **только после отдельного исправления и тестирования дефекта**.

## Данные

Для сохранения данных ключи `interval-lab:data:v1` и `interval-lab:data:v5` оставлены без изменений. GitHub Pages у двух репозиториев под `t39s.github.io` имеет **общий origin**, поэтому на одном телефоне данные могут сохраняться при переходе URL. Однако PWA-установка, service worker и кэш **зависят от пути**; новое приложение нужно установить отдельно. Рекомендуется экспорт JSON до переезда. Нельзя одновременно проводить измерения в старом и новом приложениях: они могут использовать одно хранилище и перезаписывать состояние.

## GitHub Pages

Пока стабильная версия 1.4.3 не перенесена, главная страница нового репозитория является страницей перехода на `https://t39s.github.io/dev-sandbox/interval-lab/`. Она **не выдаётся за новую стабильную сборку**.

Кандидат из `develop` публикуется в `/preview/`. После его испытаний и принятия merge `develop → main` и последующее изменение workflow дадут стабильное приложение в корне. Для мгновенного переноса принятой 1.4.3 в `main` нужен её точный исходный рабочий набор с проверкой.
