# sidesteps — самостоятельный репозиторий (переходный этап)

**Продукт:** sidesteps (прежнее название: Interval Lab).

- `main`: точка стабильной публикации. На этапе миграции содержит страницу-переходник к проверенной 1.4.3 в `dev-sandbox`. Код стабильной 1.4.3 сюда пока **не импортирован** — это не новая стабильная сборка.
- `develop`: кандидат 2.0, наследующий проверенные исходные байты Interval Lab 2.0.0-rc.2 и смену имени на sidesteps. В нём **известный дефект** кнопки «Начать раньше» остаётся до отдельного исправления.
- Pages: `/sidesteps/` — вход в стабильную версию; `/sidesteps/preview/` — испытание кандидата.
- Публикация: GitHub Actions из веток `main` и `develop` собирает оба сайта и проводит тесты кандидата.
- На GitHub требуется один раз создать репозиторий и выбрать Settings → Pages → Build and deployment → **GitHub Actions**.

Исторические версии в `t39s/dev-sandbox` при подготовке переноса не изменяются.
