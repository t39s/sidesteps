# sidesteps v0.2.1-rc.1 — отчёт кандидата

**Дата:** 12.11.2026. **Статус:** RC, не новая принятая стабильная версия.
**Стабильная baseline:** v0.2.0, Git-тег и ветка `main` без изменений.

## Состав изменений

1. **«Начать раньше»:** устранено полное пересоздание DOM каждые 80 мс при отображении результатов и отдыха; таймер обновляет только текст. Восстановленный одно-детский сеанс возвращается к экрану отдыха; переход в готовность без сообщения «Можно начинать» по досрочной кнопке.
2. **Версия:** обозначение `v0.2.1-rc.1` показывается только в подвале, отдельной последней строкой; из шапки, заголовка HTML и PWA-манифеста номер удалён.
3. **Дети:** обозначение интерфейса «Ребёнок» заменено на «Дети»; формулировка выбора одного ребёнка остаётся грамматически корректной.
4. **Графики:** до пяти последних завершённых тренировок в виде вертикальных столбцов на едином SVG, нулевая ось, подписи дат, округлённые подписи величин и точные значения в подсказке; на ширине 320/360/390 px горизонтальной прокрутки нет. Расчёт лучших результатов не изменён.

## Фактически проверено локально

- `node --check` для `app.js`, `model.js`, `sw.js` — PASS.
- `node --test tests/*.test.cjs` — 20/20 (16 существующих + 4 новые проверки).
- `python tests/browser_smoke.py` — 11/11 прежних сценариев Chromium in-memory.
- `python tests/mobile_regression.py` — 4/4: продолжительное касание взрослого, досрочное начало у ребёнка без перезагрузки и возобновление детского отдыха и компактная столбчатая диаграмма на 320/360/390 px.
- SVG-компоновка для 320 px проверена визуально по снимку экрана.
- Контрольные суммы — `sha256sum -c MANIFEST_SHA256.txt` (после формирования пакета).

## Ограничения

Chromium in-memory не проверяет живой HTTPS/Pages, установку и офлайн PWA, Web Speech или реальную iOS/Android сенсорику. Исправление KI-001 требует проверки владельцем на целевом смартфоне. Изменения только в `develop`; принятая `v0.2.0` в `main` остаётся без изменений.
