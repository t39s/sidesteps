# sidesteps v0.2.11-rc.3

Кандидат в develop на основе rc.2. Стабильная main не изменяется.

- После блока «Тренировка» добавлен блок «Анимация запуска». Три нажимаемые строки с уменьшенным треугольником и радиоотметкой: «Сияние», «Пульсация», «Без анимации». Первые два образца работают прямо в настройках.
- «Сияние» восстановлено по исходному CSS из commit 073f8b49433ea949c39773057fd5c9a83e4408c5: плавный цикл 1,8 с. «Пульсация» сохраняет текущие усиленные импульсы 2 Гц, длительностью 200 мс. «Без анимации» отключает эффект. По умолчанию оставлена «Пульсация».
- Выбор сохраняется как device.launchAnimation и не сбрасывается при перезагрузке. Применяется в обоих режимах измерения и на устройстве тренера. Уменьшение движения в браузере по-прежнему отключает все анимации.
- Крестик во время идущей попытки требует системного подтверждения, включая первые 10 секунд. Отказ сохраняет работающую попытку; время ожидания учитывается. При согласии частичное измерение фиксируется после ответа. «Отменить запуск», закрытие до старта и между попытками — без подтверждения. Команда тренера не вызывает повторный диалог.
- Формат JSON и правила импорта/экспорта сохранены. Тестовый preset: 4 отсечки, отдых 20 секунд.

Проверки: 103 Node-теста, синтаксис JavaScript, JSON и SHA-256. Новые проверки охватывают образцы и выбор во всех режимах, сохранение предпочтения при загрузке, согласие/отказ диалога, учёт времени ожидания и отсутствие двойного подтверждения. Браузерную приёмку выполняет владелец.
