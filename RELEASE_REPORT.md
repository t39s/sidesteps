# sidesteps v0.2.3-rc.2 — кандидат

Основа — стабильный выпуск v0.2.2.

- Убрана надпись «Доступ администратора». Кнопка «Назад» расположена под карточкой входа и совпадает с ней по ширине.
- При открытии вкладки «Новое упражнение» выбраны отсечки. Их количество в названии берётся из `config.json`. Режим «Старт–Стоп» можно выбрать вручную перед запуском.

- В личной истории список показывает пять предыдущих тренировок. «Все тренировки» раскрывает остальные записи, кроме последней.
- На экране личной попытки заголовок крупнее и расположен по центру, счётчик отсечек увеличен. Область касания подсвечивается жёлтым на 200 мс после засчитанного касания.
