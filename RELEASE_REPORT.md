# sidesteps v0.3.0

Модель спортивных профилей реализована по техническому плану v0.1 от 19.11.2026. Базовый профиль хранится явно в схеме v6. Миграция не перезаписывает v5. Проверка текущих полномочий отделена от сохранённых предпочтений. Удаление/переназначение и строгий импорт строят валидное состояние до одной записи.

Локальная регрессия RC5: 153 Node tests passed; синтаксис JS проверяется перед commit. Локальный Chromium заблокирован средой (socket Operation not permitted), поэтому браузерная регрессия выполняется обязательным шагом GitHub Actions. Не считать её успешной до фактического зелёного результата Actions для данного commit. Workflow собирает архив проверенного commit.

FPF Library, издание snapshot 20261118T225445Z-093327073e2f03d5: SYSE.34 — отдельная граница миграции и возврата; SIE.5 — ID/имя не доказывают общую историю установок; A.2.8.PER — разрешение проверяется при действии, сохранённый флаг не выдаёт его. Применение ограничено локальной PWA, без новых сущностей людей или учётных записей.

Каноническая эквивалентность: ключи объектов сортируются рекурсивно, коллекции проекции сортируются по ID; внутренние массивы (очередь, attemptIds, интервалы) сохраняют значимый порядок. Проекция включает профиль, workouts, attempts, archived, incomplete и относящиеся childSessions. Навигация и revision не определяют идентичность истории.

Ограничения и пользовательская проверка: README.md, KNOWN_ISSUES.md и SIDESTEPS_MIGRATION.md. Владелец принял v0.3.0 и разрешил публикацию в main 23.11.2026.

RC2: исправлена проверка исходного снимка при старте/первой миграции — новая запись другой вкладки не подменяется старым прочитанным состоянием. Два дополнительных теста моделируют изменение между чтением и записью. На RC1 commit 7504008d9cf84ebb947f58b230e7de1f3b58bccd прошли все 18 браузерных/мобильных/PWA сценариев. Для RC2 выполняется та же обязательная полная регрессия; точный результат привязан к commit в GitHub Actions.

RC3: исправлена ошибка «Нарушена связь занятия» при выборе базового профиля. Она воспроизведена на допустимом состоянии, созданном исходной v0.2.11: удаление завершённой тренировки сохраняло старую ссылку в завершённом занятии. Миграция теперь сохраняет все старые поля занятия и все имеющиеся измерения; отсутствующие тренировки помечаются `unavailableWorkoutIds` только для завершённых/принудительно закрытых занятий. Это отметка отсутствия записи, не восстановленный результат. Активные ссылки, существующие записи с неверной атрибуцией и подложные отметки отклоняются. Добавлены шесть Node regression tests и браузерный сценарий с удалением одной/всех старых тренировок. Исходный v5 сохраняется без изменения. Проверка непосредственно на данных владельца ещё не проведена.

RC4: для preview восстановлены 4 интервала и 20 секунд отдыха. Минимальный промежуток между касаниями — 500 мс.

RC5 реализует утверждённое корректирующее ТЗ редакции 1.0 от 20.11.2026. AC05–AC09 проверяются правкой и сохранением обоих комментариев в истории, запретом записи без PIN, проверкой неизменности измерений, совместимостью пустых комментариев и атомарным отказом импорта.
