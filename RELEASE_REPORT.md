# sidesteps v0.2.0 — выпускной отчёт

**Дата принятия владельцем:** 12.11.2026. **Решение:** ACCEPT — стабильная baseline `v0.2.0`.

## Состав выпуска

Изменены обозначение версии, документация и схема GitHub Pages. Предметная модель, способы измерения, сохранение локальных данных, PIN-verifier, логика отдыха и результатов **не менялись** относительно принятого к выпуску кандидата `develop`.

- Продукт: `sidesteps`.
- Ветка стабильного выпуска: `main`; выпускной тег: `v0.2.0` (создаётся workflow только после успешного deploy).
- Стабильный URL: `https://t39s.github.io/sidesteps/`.
- Испытательный URL: `https://t39s.github.io/sidesteps/preview/`.
- Предыдущий проект `Interval Lab 1.4.3` в `dev-sandbox` не изменён.

## Контроль качества и границы доказательства

- `node --check` — синтаксис `app.js`, `model.js`, `sw.js`.
- `node --test tests/*.test.cjs` — 16 тестов предметной модели, брендинга и миграционных инвариантов.
- JSON-конфигурация и PWA-манифест — синтаксическая проверка.
- `sha256sum -c MANIFEST_SHA256.txt` — проверка контрольных сумм файлов выпуска.
- В предыдущем кандидате браузерные in-memory сценарии Chromium: 11/11, но **не** полный HTTPS/PWA E2E.

Факт успешного выполнения GitHub Actions, фактической публикации URL и проверки в настоящем браузере на смартфоне фиксируется отдельно; локальные тесты не являются их заменой.

## Принятые известные ограничения

- `KI-001`: кнопка «Начать раньше» работает некорректно у взрослого и может требовать перезагрузки в детском сценарии; **ACCEPT** владельцем при принятии этой baseline.
- WebCrypto PIN, install/offline PWA, Web Speech, Wake Lock и совместимость устройств не подтверждены реальными испытаниями на целевых смартфонах.
- Нет транзакционной синхронизации нескольких вкладок, данные могут быть потеряны при очистке `localStorage`.

Нормативный перечень: [`KNOWN_ISSUES.md`](KNOWN_ISSUES.md). Исторические документы прежнего RC сохранены только как происхождение, не как действующий статус данного релиза.
